# Dev Computer web storefront and owner dashboard

Run from the root using the commands in [README.md](../README.md). This client uses the real Supabase database. Use the owner portal to add products, upload images, adjust inventory, manage offers, confirm orders, handle returns and view the audit trail.

The Expo app is in `../mobile/`. See [feature audit](../FEATURES.md) for platform parity and pending integrations. No automatic discounts or online payments are enabled.
